# `plan-dumper` — Regenerating Example Plans

The example plans committed under `standalone-app/examples/` are generated by running `EXPLAIN` against Hyper and Postgres.
`plan-dumper/queries` contains the SQL queries.
The `dump-plans.py` script regenerates the plan dumps in `standalone-app/examples/` from them.
Refresh these examples from time to time when new versions are published, so the checked-in examples stay representative.

## What Is Here

* `dump-plans.py` — runs each query against Hyper (and optionally Postgres) and writes the `EXPLAIN` output as JSON into `standalone-app/examples/<db>/`.
* `queries/` — the SQL queries to explain, including a `tpch/` subfolder of TPC-H queries.
* `setup.sql` — creates the ad-hoc and TPC-H tables and loads the tiny dataset, so cardinality estimates in the plans are meaningful.
* `tpch-data-tiny/` — a tiny TPC-H dataset loaded by `setup.sql`.

### Query Naming Conventions

The `EXPLAIN` mode is chosen from a query's filename suffix:

* `*-analyze.sql` → `EXPLAIN (…, ANALYZE)` — includes runtime measurements (Hyper and Postgres).
* `*-steps.sql` → `EXPLAIN (FORMAT JSON, OPTIMIZE STEPS)` — the optimizer's intermediate steps (Hyper only; skipped for Postgres).
* anything else → a plain `EXPLAIN (FORMAT JSON)`.

## Regenerating the Plans

**Prerequisites:**

```shell
pip3 install tableauhyperapi
```

**With the default (pip-installed) Hyper:**

```shell
cd plan-dumper
python3 dump-plans.py
```

**With a custom Hyper build:**

```shell
cd plan-dumper
python3 dump-plans.py --hyper-path ~/<workspace>/bazel-bin/hyper/tools/hyperd
```

`--hyper-path` points at the directory containing the `hyperd` binary; when omitted, the script uses the `hyperd` bundled with the pip-installed `tableauhyperapi`.

To also dump Postgres plans, run a Postgres instance on port 5433 and `pip3 install psycopg2`.
If `psycopg2` is not installed, the Postgres section is skipped automatically.

## Verifying the Result

After regenerating, build and start the app (see [Build and Deployment](../docs/BuildAndDeployment.md)), then open [localhost:8080/examples.html](http://localhost:8080/examples.html).
That page lists every example plan; click through the ones you touched to confirm they render correctly.
The `examples.html` index is generated at build time by the `standalone-app` — see its [README](../standalone-app/README.md).
